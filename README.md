# CCNA Networking Project – Cisco Packet Tracer

## 📌 Project Overview

This project is a **computer networking simulation developed using Cisco Packet Tracer**. It demonstrates the practical implementation of fundamental **CCNA networking concepts**, including network topology design, device configuration, IP addressing, routing, and connectivity testing.

The project was created to gain hands-on experience with **Cisco routers, switches, end devices, and network communication** in a simulated environment.

## 🎯 Objectives

* Design and implement a computer network using Cisco Packet Tracer.
* Configure routers and switches.
* Implement IP addressing and subnetting.
* Establish communication between different network devices.
* Configure and test routing.
* Verify network connectivity using networking commands.
* Understand practical CCNA networking concepts.

## 🌐 Network Components

The project contains a simulated network consisting of:

* Routers
* Switches
* End devices
* Network connections
* IP-addressed interfaces

The devices are connected according to the designed network topology to enable communication between different parts of the network.

## ⚙️ Key Concepts Demonstrated

### 1. Network Topology

Designed a structured network topology using Cisco Packet Tracer and connected routers, switches, and end devices.

### 2. IP Addressing

Configured IPv4 addresses for network interfaces and end devices to establish communication within the network.

### 3. Subnetting

Applied subnetting concepts to divide the network into appropriate logical network segments.

### 4. Router Configuration

Configured router interfaces and basic Cisco IOS commands to establish network connectivity.

### 5. Switch Configuration

Configured switches and connected end devices to the appropriate network segments.

### 6. Routing

Implemented routing between different networks and verified that packets could travel between network segments.

### 7. Connectivity Testing

Used commands such as:

```text
ping
traceroute
ipconfig
show ip interface brief
show running-config
```

to verify device configuration and network connectivity.

## 🧪 Testing

Network connectivity was tested between different devices using **ping** and other Cisco IOS verification commands.

The configurations were checked to ensure that the connected devices could communicate successfully across the simulated network.

## ▶️ How to Run the Project

1. Install **Cisco Packet Tracer**.
2. Clone or download this repository.
3. Open Cisco Packet Tracer.
4. Open the file:

```text
CCNA.PROJECT.pkt
```

5. Inspect the network topology and device configurations.
6. Use the Cisco IOS CLI to verify the configurations.
7. Test connectivity between the required devices using `ping`.
